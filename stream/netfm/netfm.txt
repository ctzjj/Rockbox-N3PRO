# 网络收音机预设 (Network radio presets)
#
# 每行一个电台，格式:  名称,地址

#
# 支持:
#   - HTTP / HTTPS 的 MP3 直链 (Icecast/Shoutcast 连续流)
#   - HLS 直播 (m3u8，MPEG-TS 内的 AAC 或 MPEG 音频)
#
# 提示: 部分电台地址带有时效 token，过期后需要重新获取。
#       本文件位于存储卡的 .rockbox/stream/netfm/netfm.txt，可直接编辑。
